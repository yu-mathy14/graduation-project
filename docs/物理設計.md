# 物理設計
## テーブル設計書

### テーブル分割
| No | テーブル物理名 | 論理名 | 概要 |
| :----: | :----: | :----: | :----: |
| 1 | teams | チーム | 登録済みのチームを管理 |
| 2 | players | 選手 | 各チームに所属している選手を管理 |
| 3 | games | 試合 | 登録済みの試合を管理 |
| 4 | stats | スタッツ | 試合ごとの選手のスタッツを管理 |

---

### 1. teams(チーム)
| カラム物理名 | データ型 | 制約 | 論理名 |
| :----: | :----: | :---- | :----: |
| team_id | SERIAL | PRIMARY KEY | チームID |
| team_name | VARCHAR(30) | NOT NULL, UNIQUE | チーム名 |
| team_color | VARCHAR(7) | NOT NULL, DEFAULT '#FFFFFF' | チームカラー |

### 2. players(選手)
| カラム物理名 | データ型 | 制約 | 論理名 |
| :----: | :----: | :---- | :----: |
| player_id | SERIAL | PRIMARY KEY | 選手ID |
| team_id | INTEGER | NOT NULL, FK->teams.team_id | チームID |
| player_name_kanji | VARCHAR(30) | NOT NULL | 選手名(漢字) |
| player_name_kana | VARCHAR(30) | NOT NULL | 選手名(仮名) |
| jersey_number | INTEGER | NOT NULL, CHECK (jersey_number > 0) | 背番号 |
| alma_mater | VARCHAR(30) | NOT NULL, DEFAULT '未設定' | 出身校 |
| height | INTEGER | CHECK (height > 50) | 身長(cm) |
| weight | INTEGER | CHECK (weight > 3) | 体重(kg) |

---
テーブルレベルでのUNIQUE制約
- UNIQUE (team_id, jersey_number)

### 3. games(試合)
| カラム物理名 | データ型 | 制約 | 論理名 |
| :----: | :----: | :---- | :----: |
| game_id | SERIAL | PRIMARY KEY | 試合ID |
| tipoff_time | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 試合開始日時 |
| home_team_id | INTEGER | NOT NULL, FK->teams.team_id | ホームチームID |
| away_team_id | INTEGER | NOT NULL, FK->teams.team_id | アウェイチームID |

---
テーブルレベルでのチェック制約
- CHECK (home_team_id <> away_team_id)

### 4. stats(スタッツ)
| カラム物理名 | データ型 | 制約 | 論理名 |
| :----: | :----: | :---- | :----: |
| player_id | INTEGER | NOT NULL, FK->players.player_id, PK(複合) | 選手ID |
| game_id | INTEGER | NOT NULL, FK->games.game_id, PK(複合) | 試合ID |
| p3_a | INTEGER | NOT NULL, DEFAULT 0, CHECK (p3_a >= 0) | 3点シュート試行回数 |
| p3_m | INTEGER | NOT NULL, DEFAULT 0, CHECK (p3_m >= 0) | 3点シュート成功回数 |
| p2_a | INTEGER | NOT NULL, DEFAULT 0, CHECK (p2_a >= 0) | 2点シュート試行回数 |
| p2_m | INTEGER | NOT NULL, DEFAULT 0, CHECK (p2_m >= 0) | 2点シュート成功回数 |
| ft_a | INTEGER | NOT NULL, DEFAULT 0, CHECK (ft_a >= 0) | フリースロー試行回数 |
| ft_m | INTEGER | NOT NULL, DEFAULT 0, CHECK (ft_m >= 0) | フリースロー成功回数 |
| o_rbd | INTEGER | NOT NULL, DEFAULT 0, CHECK (o_rbd >= 0) | オフェンスリバウンド数 |
| d_rbd | INTEGER | NOT NULL, DEFAULT 0, CHECK (d_rbd >= 0) | ディフェンスリバウンド数 |
| stl | INTEGER | NOT NULL, DEFAULT 0, CHECK (stl >= 0) | スティール数 |
| blk | INTEGER | NOT NULL, DEFAULT 0, CHECK (blk >= 0) | シュートブロック数 |
| tov | INTEGER | NOT NULL, DEFAULT 0, CHECK (tov >= 0) | ターンオーバー数 |
| pf | INTEGER | NOT NULL, DEFAULT 0, CHECK (pf >= 0) | パーソナルファウル数 |
| tf | INTEGER | NOT NULL, DEFAULT 0, CHECK (tf >= 0) | テクニカルファウル数 |
| fo | INTEGER | NOT NULL, DEFAULT 0, CHECK (fo >= 0) | ファウルオン数 |
| dq | INTEGER | NOT NULL, DEFAULT 0, CHECK (dq BETWEEN 0 AND 1) | 退場回数 |
| play_sec | INTEGER | NOT NULL, DEFAULT 0, CHECK (play_sec >= 0) | 試合出場時間(秒) |

---
主キー
- PRIMARY KEY (player_id, game_id)

テーブルレベルでのチェック制約
- CHECK (p3_m <= p3_a)
- CHECK (p2_m <= p2_a)
- CHECK (ft_m <= ft_a)

備考：選手が試合のホームチームまたはアウェイチームに所属していることをアプリケーション側で検証する

---

### テーブル間リレーション一覧
| 親テーブル | 子テーブル | カーディナリティ | 備考 |
| :----: | :----: | :----: | :----: |
| teams | players | 1:0以上 | 1つのチームに複数の選手が所属する |
| teams | games | 1:0以上 | 1つのチームはホームチームとして複数試合に参加する |
| teams | games | 1:0以上 | 1つのチームはアウェイチームとして複数試合に参加する |
| players | stats | 1:0以上 | 1選手が持つスタッツは複数試合分 |
| games | stats | 1:0以上 | 1試合に対するスタッツは複数選手分 |

## テーブル作成文
teamsテーブル
```SQL
CREATE TABLE teams (
  team_id SERIAL PRIMARY KEY,
  team_name VARCHAR(30) NOT NULL UNIQUE,
  team_color VARCHAR(7) NOT NULL DEFAULT '#FFFFFF'
);
```

---

playersテーブル
```SQL
CREATE TABLE players (
  player_id SERIAL PRIMARY KEY,
  team_id INTEGER NOT NULL REFERENCES teams(team_id),

  player_name_kanji VARCHAR(30) NOT NULL,
  player_name_kana VARCHAR(30) NOT NULL,

  jersey_number INTEGER NOT NULL CHECK (jersey_number > 0),

  alma_mater VARCHAR(30) NOT NULL DEFAULT '未設定',
  
  height INTEGER CHECK (height > 50),
  weight INTEGER CHECK (weight > 3),

  UNIQUE (team_id, jersey_number)
);
```
---

gamesテーブル
```SQL
CREATE TABLE games (
  game_id SERIAL PRIMARY KEY,
  tipoff_time TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  home_team_id INTEGER NOT NULL REFERENCES teams(team_id),
  away_team_id INTEGER NOT NULL REFERENCES teams(team_id),

  -- テーブル単位でのCHECK制約
  CHECK (home_team_id <> away_team_id)
);
```

---

statsテーブル
```SQL
CREATE TABLE stats (
  player_id INTEGER NOT NULL REFERENCES players(player_id),
  game_id INTEGER NOT NULL REFERENCES games(game_id),
  

  p3_a INTEGER NOT NULL DEFAULT 0 CHECK (p3_a >= 0),
  p3_m INTEGER NOT NULL DEFAULT 0 CHECK (p3_m >= 0),

  p2_a INTEGER NOT NULL DEFAULT 0 CHECK (p2_a >= 0),
  p2_m INTEGER NOT NULL DEFAULT 0 CHECK (p2_m >= 0),

  ft_a INTEGER NOT NULL DEFAULT 0 CHECK (ft_a >= 0),
  ft_m INTEGER NOT NULL DEFAULT 0 CHECK (ft_m >= 0),

  o_rbd INTEGER NOT NULL DEFAULT 0 CHECK (o_rbd >= 0),
  d_rbd INTEGER NOT NULL DEFAULT 0 CHECK (d_rbd >= 0),

  stl INTEGER NOT NULL DEFAULT 0 CHECK (stl >= 0),
  blk INTEGER NOT NULL DEFAULT 0 CHECK (blk >= 0),
  tov INTEGER NOT NULL DEFAULT 0 CHECK (tov >= 0),
  pf INTEGER NOT NULL DEFAULT 0 CHECK (pf >= 0),
  tf INTEGER NOT NULL DEFAULT 0 CHECK (tf >= 0),
  fo INTEGER NOT NULL DEFAULT 0 CHECK (fo >= 0),
  dq INTEGER NOT NULL DEFAULT 0 CHECK (dq BETWEEN 0 AND 1),

  play_sec INTEGER NOT NULL DEFAULT 0 CHECK (play_sec >= 0),
  
  PRIMARY KEY (player_id, game_id),

  -- テーブル単位でのCHECK制約
  CHECK (p3_m <= p3_a),
  CHECK (p2_m <= p2_a),
  CHECK (ft_m <= ft_a)
);
```
