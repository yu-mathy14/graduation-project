# 概念設計

## 1. エンティティ
- チーム
- 選手
- 試合
- スタッツ

---

## 2. 属性
### チーム
- チームID
- チーム名
- チームカラー(カラーコード形式)

### 選手
- 選手ID
- チームID
- 選手名(漢字)
- 選手名(仮名)
- 背番号
- 出身校
- 身長(cm)
- 体重(kg)

### 試合
- 試合ID
- 試合開始日時
- ホームチームID
- アウェイチームID
- ホーム最終スコア
- アウェイ最終スコア

### スタッツ
- 選手ID
- 試合ID
- 3点シュート試行回数
- 3点シュート成功回数
- 2点シュート試行回数
- 2点シュート成功回数
- フリースロー試行回数
- フリースロー成功回数
- オフェンスリバウンド数
- ディフェンスリバウンド数
- スティール数
- シュートブロック数
- ターンオーバー数
- パーソナルファウル数
- テクニカルファウル数
- ファウルオン数
- 退場フラグ
- 試合出場時間

---

## 3. 関連(カーディナリティ含む)
- チーム 1->多 選手
- チーム 1->多 試合(HOME)
- チーム 1->多 試合(AWAY)
- 選手 1->多 スタッツ
- 試合 1->多 スタッツ
