# スタッツ新規登録の二段階入力設計

## 1. 変更概要
スタッツ新規登録画面を、現在の1段階入力から2段階入力へ変更する。<br>
現在は、選手1人ずつすべてのスタッツを入力しているが、以下のように入力内容を分ける。
```
第1段階
選手ごとのスタッツを入力
↓
第2段階
全選手の出場時間・得点関連スタッツを表形式で入力
↓
整合性チェック
↓
登録
```

## 2. 変更理由
現在のスタッツ入力では、選手ごとのスタッツと、チーム全体で整合性を確認する必要がある項目が同じ入力画面に含まれている。スタッツを入力しているが、以下のように入力内容を分ける。

特に、
* 出場時間の合計
* 得点の合計
* 試合の最終スコアとの一致

は、1選手だけでは判断できず、全選手の入力内容をまとめて確認する必要がある。<br>
そこで、選手単位で入力する項目と、全選手を一覧で確認しながら入力する項目を分離する。

## 3. 第1段階：選手ごとのスタッツ入力
### 入力する項目
第1段階では、出場時間と得点関連の項目を除いたスタッツを入力する。
* OR
* DR
* AST
* STL
* BLK
* TOV
* PF
* TF
* FO
* DQ

### 画面の流れ
```
選手選択
↓
選手のスタッツ入力
↓
Yupによるバリデーション
↓
「次の選手へ」
↓
次の選手
```
最後の選手まで入力すると、第2段階へ進む。

### 第1段階で行うチェック
選手単位で完結する整合性チェックを行う。<br>
`PF + TF ≦ 5`

その他の入力値についても、既存のYupによるバリデーションを行う。
* 0以上の整数
* 上限値
* 0・1のみ許可する項目

など、各項目に設定されているルールを適用する。

## 4. 第2段階：全選手の出場時間・得点関連スタッツ入力
第1段階の入力が完了したら、所属選手全員を表形式で表示する。
### 入力する項目
* 3P試投（p3A）
* 3P成功（p3M）
* 2P試投（p2A）
* 2P成功（p2M）
* FT試投（ftA）
* FT成功（ftM）
* 出場時間（playSec）

### 得点について
得点はユーザーが直接入力しない。<br>
以下のスタッツから自動計算して表示する。
```
得点 ＝ 3P成功 × 3 ＋ 2P成功 × 2 ＋ FT成功
```
これにより、入力された成功数と得点の不整合を防ぐ。

### 画面イメージ
| 選手  | 3P試投 | 3P成功 | 2P試投 | 2P成功 | FT試投 | FT成功 | 得点 | 出場時間  |
| --- | ---- | ---- | ---- | ---- | ---- | ---- | -- | ----- |
| #7  | 5    | 2    | 8    | 4    | 2    | 1    | 15 | 25:00 |
| #10 | 3    | 1    | 9    | 5    | 2    | 2    | 15 | 23:00 |
| #15 | 1    | 0    | 5    | 2    | 0    | 0    | 4  | 20:00 |

## 5. 第2段階で行う整合性チェック
第2段階では、選手単位だけではなく、全選手を対象とした整合性チェックを行う。
### 5-1. シュート成功数の整合性
```
3P成功 ≦ 3P試投
2P成功 ≦ 2P試投
FT成功 ≦ FT試投
```

### 5-2. 出場時間の合計
所属選手全員の出場時間を合計し、12,000秒になることを確認する。
```
全選手の出場時間合計 ＝ 12,000秒
```
一致しない場合はエラーを表示し、登録できないようにする。

### 5-3. 得点合計
全選手の得点を合計し、試合の最終スコアと一致することを確認する。
```
全選手の得点合計 ＝ 試合情報に登録されている最終スコア
```
一致しない場合はエラーを表示し、登録できないようにする。

## 6. 登録までの全体フロー
### 第1段階
```
選手A
↓
スタッツ入力・Yup検証
↓
選手B
↓
スタッツ入力・Yup検証
↓
選手C
↓
スタッツ入力・Yup検証
↓
全選手完了
```

### 第2段階
```
全選手を表形式で表示
↓
3P・2P・FT・出場時間を入力
↓
選手単位の整合性チェック
↓
出場時間合計チェック
↓
得点合計チェック
↓
すべてのチェックに成功
↓
createStats()
↓
DB登録
```
## 7. エラー表示
第2段階では、複数のエラーをまとめて確認できるようにする。<br>
例えば、
```
背番号7 田中太郎：3P成功は3P試投以下で入力してください。
出場時間の合計は12,000秒になるように入力してください。
選手スタッツの得点合計と試合の最終スコアが一致するように入力してください。
```
のように、複数のエラーがある場合はまとめて表示する。

これにより、
```
修正
↓
再度登録
↓
別のエラーを確認
↓
再度修正
```
という繰り返しを減らす。

## 8. 第1段階と第2段階の役割
| 段階   | 主な役割 |
| ---- | ---- |
| 第1段階 | 選手ごとのスタッツ入力 |
| 第1段階 | 選手単位のYupバリデーション |
| 第1段階 | 選手単位で完結する整合性チェック |
| 第2段階 | 全選手の3P・2P・FT・出場時間を入力 |
| 第2段階 | 全選手を表形式で確認 |
| 第2段階 | 得点を自動計算 |
| 第2段階 | 出場時間合計をチェック |
| 第2段階 | 得点合計と試合最終スコアをチェック |
| 第2段階 | すべてのチェック成功後に登録 |

## 9. 今回の変更で目指す状態
スタッツ新規登録を、<br>
`選手単位の入力`と`チーム全体の整合性確認`<br>
に分離する。

これにより、<br>
入力内容の役割を明確にし、最後に全選手のスタッツを一覧で確認したうえで登録できる構成にする。
