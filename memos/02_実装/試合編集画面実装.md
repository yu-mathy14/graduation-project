# 試合編集画面で日時を入力欄に表示するための変換

## 1. 編集画面では日時の変換が必要

試合登録時は、

```tsx
new Date(`${tipoffTimeRaw}:00+09:00`)
```

として、入力された日時を日本時間として保存している。

一方、試合編集画面では、Prismaから取得した `game.tipoffTime` は `Date` 型である。

```tsx
game.tipoffTime
```

のままでは、

```tsx
<input type="datetime-local" />
```

の `defaultValue` に設定できない。

`datetime-local` の `defaultValue` には、以下のような文字列が必要になる。

```text
2026-09-10T19:00
```

そのため、Prismaから取得した `Date` 型を `datetime-local` 用の文字列に変換する。

---

## 2. 日本時間に変換する

まず、`game.tipoffTime` を日本時間として文字列に変換する。

```tsx
const tipoffTimeValue = game.tipoffTime.toLocaleString("sv-SE", {
  timeZone: "Asia/Tokyo",
});
```

例えば、以下のような文字列になる。

```text
2026-09-10 19:00:00
```

`timeZone: "Asia/Tokyo"` を指定することで、日本時間として表示できる。

---

## 3. `datetime-local` 用の形式に変換する

`datetime-local` では、<br>
日時と時刻の間を `T` で区切って次のように変換する必要がある。
```text
2026-09-10 19:00:00
 ↓
2026-09-10T19:00:00
```

--- 

```tsx
.replace(" ", "T")
```

を使用して、空白を `T` に置き換える。

さらに、`datetime-local` では秒を表示する必要がないため、

```tsx
.slice(0, 16)
```

で先頭16文字を取得する。

最終的に、

```text
2026-09-10T19:00
```

となる。

---

## 4. 実際のコード

```tsx
const tipoffTimeValue = game.tipoffTime.toLocaleString("sv-SE", {
  timeZone: "Asia/Tokyo",
}).replace(" ", "T").slice(0, 16);
```

作成した `tipoffTimeValue` を、`datetime-local` の `defaultValue` に設定する。

```tsx
<input
  id="tipoffTime"
  name="tipoffTime"
  type="datetime-local"
  required
  defaultValue={tipoffTimeValue}
/>
```

これにより、試合編集画面を開いたときに登録済みの試合開始日時が入力欄に表示される。

---

## 5. 日時の変換の流れ

```text
Prismaから取得
        ↓
Date型
        ↓
Asia/Tokyoを指定して日本時間に変換
        ↓
2026-09-10 19:00:00
        ↓
空白をTに変更
        ↓
2026-09-10T19:00:00
        ↓
先頭16文字を取得
        ↓
2026-09-10T19:00
        ↓
datetime-localのdefaultValueへ設定
```

---

## 6. 登録時と編集時の違い

### 試合登録

入力された文字列に日本時間を表す `+09:00` を付けて `Date` 型に変換する。

```text
2026-09-10T19:00
        ↓
2026-09-10T19:00:00+09:00
        ↓
Date型
        ↓
DBへ保存
```

### 試合編集

DBから取得した `Date` 型を、日本時間の `datetime-local` 用文字列に変換する。

```text
DBから取得
        ↓
Date型
        ↓
Asia/Tokyo
        ↓
2026-09-10T19:00
        ↓
datetime-localの入力欄に表示
```

このように、**登録時と編集時では日時の変換方向が逆になる**。

---

## 7. 動作確認

試合編集画面を開き、既存の試合開始日時が入力欄に正しく表示されることを確認する。

例えば、DBに日本時間の

```text
2026/9/10 19:00
```

として保存されている試合を編集すると、入力欄には

```text
2026-09-10 19:00
```

として表示される。

日時を変更して更新した場合も、

```tsx
new Date(`${tipoffTimeRaw}:00+09:00`)
```

によって日本時間として保存される。
