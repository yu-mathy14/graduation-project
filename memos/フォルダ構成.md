# フォルダ構成

## 現在のフォルダ構成
新しい画面を作るたびに更新していくものとする

```
app/teams
     │
     ├── page.tsx // チーム一覧画面
     ├── [teamId]
     │    ├── page.tsx // チーム詳細画面
     │    ├── players
     │    │   ├── page.tsx // 所属選手一覧画面
     │    │   ├── [playerId]
     │    │   │   ├── page.tsx // 選手詳細画面
     │    │   │   └── edit
     │    │   │       └── page.tsx // 選手編集画面
     │    │   └── new
     │    │       └── page.tsx // 選手登録画面
     │    └── edit
     │        └── page.tsx // チーム編集画面
     └── new
         └── page.tsx // チーム登録画面

app/games

     │
     ├── page.tsx // 試合一覧画面
     │
     ├── [gameId]
     │    ├── page.tsx // 試合詳細 + スタッツ一覧画面
     │    │
     │    ├── edit
     │    │   └── page.tsx // 試合編集画面
     │    │
     │    └── stats
     │        └── new
     │            ├── page.tsx // スタッツ登録画面のデータ取得・表示
     │            ├── actions.ts // スタッツをDBへ登録するServer Action
     │            ├── types.ts // Player・PlayerStatsなどの型定義
     │            │
     │            └── components
     │                ├── StatsNewForm.tsx // スタッツ入力画面全体・ステップを管理
     │                ├── PlayerSelect.tsx // 出場選手を選択
     │                └── PlayerStatsInput.tsx // 1人分のスタッツを入力
     │
     └── new
         └── page.tsx // 試合登録画面
```
