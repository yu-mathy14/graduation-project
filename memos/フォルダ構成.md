# フォルダ構成

## 現在のフォルダ構成
新しい画面を作るたびに更新していくものとする

```
app/teams
     │
     ├── page.tsx // チーム一覧画面
     ├── [teamId]
     │    ├── page.tsx // チーム詳細画面
     │    ├── players
     │    │   ├── page.tsx // 所属選手一覧画面
     │    │   └──[playerId]
     │    │       └── page.tsx // 選手詳細画面
     │    └── edit
     │        └── page.tsx // チーム編集画面⭐️
     └── new
         └── page.tsx // チーム登録画面
```
