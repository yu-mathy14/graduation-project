# 試合日時の日本時間対応

## 試合開始日時を日本時間として扱う

### 完成系のイメージ

```text
(入力)
2026/9/10 19:00

↓

(保存)
日本時間（JST / UTC+09:00）として保存

↓

(表示)
2026/9/10 19:00
```

---

## 1. データベースの日時型を見直す

もともとの `games` テーブルでは、試合開始日時を以下のように定義していた。

```sql
"tipoff_time" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
```

`TIMESTAMP` はタイムゾーンを持たない日時を扱う。

今回、試合開始日時を日本時間として正しく扱いたいため、`TIMESTAMPTZ` に変更することにした。

```sql
"tipoff_time" TIMESTAMPTZ(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
```

### 変更内容

```text
TIMESTAMP(3)
↓
TIMESTAMPTZ(3)
```

`TIMESTAMPTZ` は、日時を「世界のどの時点なのか」という情報を含めて扱える。

今回のアプリは日本国内で使用することを想定しているため、入力された日時を日本時間として扱う。

---

## 2. Prismaの設定

`schema.prisma` の `Games` modelは変更しない。

```prisma
model Games {
  gameId     Int      @id @default(autoincrement()) @map("game_id")
  tipoffTime DateTime @default(now()) @map("tipoff_time")
  // ...
}
```

Prismaでは `DateTime` のままとし、実際のPostgreSQL側の型を `TIMESTAMPTZ(3)` に変更する。

---

## 3. マイグレーション

Prismaで空のマイグレーションを作成し、`migration.sql` を編集した。

```bash
pnpm exec prisma migrate dev --create-only --name change_tipoff_time_to_timestamptz
```

作成された `migration.sql` に以下を記述した。

```sql
ALTER TABLE "games"
ALTER COLUMN "tipoff_time" TYPE TIMESTAMPTZ(3);
```

その後、マイグレーションを適用した。

```bash
pnpm exec prisma migrate dev
```

適用後、

```bash
pnpm exec prisma migrate status
```

を実行し、

```text
Database schema is up to date!
```

となることを確認した。

---

## 4. 入力された日時を日本時間として扱う

試合登録画面では、`datetime-local` を使用して試合開始日時を入力する。

```tsx
<input
  id="tipoffTime"
  name="tipoffTime"
  type="datetime-local"
  required
/>
```

`datetime-local` から取得した値には、タイムゾーン情報が含まれていない。

例えば、

```text
2026-09-10T19:00
```

という値が送られてくる。

そこで、`+09:00` を付けて日本時間として明示する。

```tsx
const tipoffTimeRaw = formData.get("tipoffTime") as string;

const game = await prisma.games.create({
  data: {
    tipoffTime: new Date(`${tipoffTimeRaw}:00+09:00`),
    // ...
  },
});
```

この、

```text
+09:00
```

が日本時間（JST / UTC+09:00）を表している。

そのため、

```text
2026-09-10T19:00
```

を、

```text
2026-09-10T19:00:00+09:00
```

として扱うことができる。

---

## 5. 日本時間で表示する

試合一覧・試合詳細では、保存されている日時を日本時間として表示する。

```tsx
g.tipoffTime.toLocaleString("ja-JP", {
  timeZone: "Asia/Tokyo",
  year: "numeric",
  month: "numeric",
  day: "numeric",
  hour: "2-digit",
  minute: "2-digit",
})
```

`timeZone: "Asia/Tokyo"` を指定することで、日本時間として表示する。

表示形式は、

```text
2026/9/10 19:00
```

とする。

秒まで表示する必要はないため、`second` は指定していない。

---

## 6. 動作確認

試合登録画面で、

```text
2026/9/10 19:00
```

と入力して試合を登録した。

その後、試合詳細画面で、

```text
2026/9/10 19:00
```

と表示されることを確認した。

これにより、

```text
datetime-localで日時を入力
        ↓
+09:00を付けて日本時間として解釈
        ↓
TIMESTAMPTZ(3)で保存
        ↓
Asia/Tokyoを指定して表示
```

という流れで、日本時間を一貫して扱えるようにした。
