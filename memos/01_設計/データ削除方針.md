# 各テーブルデータ削除方針

## 削除時影響がある関連データ
| データ(削除対象) | 検討事項 |
| ----- | ----- |
| チーム | ・所属選手がいる場合<br>・試合参加歴がある場合 |
| 選手 | ・スタッツがある場合 |
| 試合 | ・スタッツがある場合 |
| スタッツ | ・特定の試合の特定の選手のスタッツのみの削除を許可するか |

---

## 削除可否の条件
### 選手
影響がある関連データは`スタッツ`
- スタッツが存在する選手：削除不可
- スタッツが存在しない選手：削除可能

### 試合
影響がある関連データは`スタッツ`
- スタッツが存在する場合：削除不可
- スタッツが存在しない場合：削除可能

### チーム
影響がある関連データは`選手`と`試合`
- 所属選手が存在する場合：削除不可
- ホーム/アウェイチームとして参加した試合データがある：削除不可
- 所属選手も参加した試合データもない：削除可能

削除可能な状態を限定することで、過去の試合や選手記録を壊さない。

### スタッツ
影響がある関連データは`選手 × 試合`の組み合わせ
- 削除機能を付けずに、編集画面で全項目0で入力して更新する

---

## 削除成功時の遷移先
### 選手
遷移先：所属選手一覧画面
```
/teams/[teamId]/players
```
```
選手詳細
↓
削除
↓
Server Action
↓
Player削除
↓
所属選手一覧へ戻る
```
### 試合
遷移先：試合一覧画面
```
/games
```
```
試合詳細
↓
削除
↓
Server Action
↓
Game削除
↓
試合一覧へ戻る
```

### チーム
遷移先：チーム一覧画面
```
/teams
```
```
チーム詳細
↓
削除
↓
Server Action
↓
Team削除
↓
チーム一覧へ戻る
```

### スタッツ
削除機能なし

---

## 削除できない場合のメッセージ
### 選手
理由：スタッツが存在する
```
この選手には試合スタッツが登録されているため、削除できません。
```

### 試合
理由：スタッツが存在する
```
この試合にはスタッツが登録されているため、削除できません。
```

### チーム
理由1：所属選手が存在する
```
このチームには所属選手がいるため、削除できません。
```

理由2：試合参加歴がある
```
このチームは試合に参加した記録があるため、削除できません。
```

理由3：理由1 かつ 理由2
```
このチームは以下の理由で削除できません。
・所属選手がいる
・試合に参加した記録がある
```

### スタッツ
削除機能なし
