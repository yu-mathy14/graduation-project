# 削除機能設計
全テーブル共通の削除機能を設計する。

## イメージ

```text
詳細画面表示
  ↓
削除可否を確認
  ↓
┌─────────────────┐
│ 削除可能          │ → [削除]リンクを表示
│ 削除不可          │ → [削除]リンクを非表示
└─────────────────┘
          ↓
      [削除]押下
          ↓
/delete/page.tsxへ遷移
          ↓
   削除可否を再確認
       ↓       ↓
     可能      不可
       ↓        ↓
 削除確認画面  エラーメッセージ
    ↓    ↓            ↓
 [削除] [キャンセル]  [了解]
    ↓           ↓     ↓
Server Action   詳細画面へ戻る
    ↓
削除可否を再判定
  ↓         ↓
 削除      エラー
  ↓         ↓
一覧画面へ  詳細画面へ
  遷移       戻る
```

## 削除機能の流れ

### 0. 詳細画面表示
詳細画面に編集ボタンの他、削除リンクもある状態。

### 1. 削除可否を判定（1回目：画面側）
UI向上のため、詳細画面表示時に削除可否を確認する。

| 削除対象候補 | 削除可能条件 |
| ---- | ----------- |
| 選手 | スタッツなし |
| 試合 | スタッツなし |
| チーム | 所属選手も試合参加歴もなし |
| スタッツ | × |

### 2. 削除リンクの表示切替
- 削除可能な場合は、詳細画面に[削除]リンクを表示する
- 削除不可の場合は、詳細画面に[削除]リンクを表示しない
- 削除不可の場合は、削除できない理由を詳細画面に表示する

### 3. [削除]リンク押下後、削除確認画面へ遷移
`/delete/page.tsx`へ遷移する。<br>
削除可能な場合は、以下の確認画面を表示する。
```text
この〇〇を本当に削除しますか？
```
※ 〇〇は選手・試合・チームのいずれか。

- [キャンセル]押下 → データを削除せず、詳細画面へ戻る
- [削除]押下 → Server Actionを実行する

### 4. `/delete/page.tsx`で削除可否を再確認
削除画面を直接URLから開いた場合や、詳細画面表示後に関連データが追加された場合に備えて、削除可否を確認する。<br>
削除不可の場合は、以下のエラーメッセージを表示する。
```text
削除できません。
```
詳細な理由もあわせて表示し、[了解]押下で詳細画面へ戻る。

### 5. [削除]押下後、削除可否を判定（Server Action側）
データ保護・安全性のため、Server Action側でも削除可否を再度確認する。

### 6. 削除結果の処理
削除可能な場合はデータを削除し、一覧画面に戻る。
Server Action側で削除不可と判定された場合は、<br>
エラーメッセージを表示し、[了解]押下で詳細画面に戻る。
