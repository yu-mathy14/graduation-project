# フォルダ構成

## 現在のフォルダ構成

新しい画面やファイルを作るたびに更新していくものとする

app/teams
     ├── page.tsx // チーム一覧画面
     ├── schema.ts // チーム登録・編集の入力ルール
     ├── [teamId]
     │    ├── page.tsx // チーム詳細画面
     │    ├── players
     │    │   ├── page.tsx // 所属選手一覧画面
     │    │   ├── schema.ts // 選手登録・編集の入力ルール
     │    │   ├── [playerId]
     │    │   │   ├── page.tsx // 選手詳細画面
     │    │   │   ├── edit
     │    │   │   │   ├── page.tsx // 選手編集画面
     │    │   │   │   ├── actions.ts // 選手編集 + 背番号重複チェック
     │    │   │   │   └── components/
     │    │   │   │       └── PlayerForm.tsx　// 選手編集フォーム
     │    │   │   └── delete
     │    │   │       ├── page.tsx // 選手削除確認画面
     │    │   │       └── actions.ts // 削除可否判定 + 選手削除
     │    │   └── new
     │    │       ├── page.tsx // 選手登録画面
     │    │       ├── actions.ts // 選手新規登録 + 背番号重複チェック
     │    │       └── components/
     │    │           └── PlayerForm.tsx　// 選手新規登録フォーム
     │    └── edit
     │        ├── page.tsx // チーム編集画面
     │        ├── actions.ts // チーム編集 + 自分自身を除いた重複チェック
     │        └── components/
     │            └── TeamForm.tsx　// チーム編集フォーム
     └── new
         ├── page.tsx // チーム登録画面
         ├── actions.ts // チーム新規登録 + 重複チェック
         └── components/
             └── TeamForm.tsx // チーム新規登録フォーム
