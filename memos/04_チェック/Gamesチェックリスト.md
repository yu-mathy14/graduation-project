## Games新規登録
### Yupによるバリデーション
1. 正常登録
2. 日時空欄
3. 日時の不正形式
4. ホームチーム未選択
5. アウェイチーム未選択
6. ホーム・アウェイ同一チーム
7. スコア空欄
8. スコア負数
9. スコア小数

### 整合性チェック
#### チームの所属選手数
1. 所属選手が5人以上のチームを選択できる
2. 所属選手が4人以下のチームを選択できない
3. ホームチームの所属選手が5人未満の場合、試合を登録できない
4. アウェイチームの所属選手が5人未満の場合、試合を登録できない
5. Server Actionで所属選手数5人未満のチームを登録できない

## Games編集
### Yupによるバリデーション
1. 正常な編集
2. 試合開始日時を空欄
3. 試合開始日時を不正形式
4. ホームチーム未選択
5. アウェイチーム未選択
6. ホーム・アウェイを同じチームに変更
7. ホームスコアを空欄
8. ホームスコアを負数
9. ホームスコアを小数
10. アウェイスコアを空欄
11. アウェイスコアを負数
12. アウェイスコアを小数

### 整合性チェック
#### チームの所属選手数
1. 所属選手が5人以上のチームを選択できる
2. 所属選手が4人以下のチームを選択できない
3. ホームチームの所属選手が5人未満の場合、試合を更新できない
4. アウェイチームの所属選手が5人未満の場合、試合を更新できない
5. Server Actionで所属選手数5人未満のチームに変更できない
