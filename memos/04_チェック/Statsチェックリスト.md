2. 不正なスタッツの場合、エラーメッセージが表示される
3. 不正なスタッツの場合、次の選手へ進まない
4. エラーを修正すると、エラーメッセージが消えて次の選手へ進める

#### 20. 「確認する」の動作
1. 第1段階の全選手入力が正しい場合、最初の確認画面へ進める
2. 第2段階の入力が正しい場合、最終確認画面へ進める
3. 第1段階・第2段階のいずれかに不正なスタッツがある場合、確認画面へ進まない
4. バリデーションエラーがある場合、エラーメッセージが表示される
5. バリデーションエラーがある場合、DB登録されない

### 確認画面
#### 第1段階確認
1. 第1段階の全選手入力が完了すると確認画面が表示される
2. 所属選手全員が表形式で表示される
3. 出場選手は出場として表示される
4. 出場していない選手はDNPとして表示される
5. OR・DR・AST・STL・BLK・TO・PF・TF・FO・DQの入力内容が表示される
6. 「第1段階入力に戻る」で入力画面に戻れる
7. 「出場時間・得点入力へ」で第2段階へ進める
8. 第1段階確認画面でDB登録されない

#### 第2段階確認
1. 第2段階の入力内容が正しい場合、確認画面が表示される
2. 全選手が表形式で表示される
3. 3P試投・3P成功・2P試投・2P成功・FT試投・FT成功が表示される
4. 自動計算された得点が表示される
5. 出場時間が表示される
6. 出場時間合計が表示される
7. 得点合計と試合の最終スコアが表示される
8. 背番号・選手名が横スクロール時も固定される
9. 「出場時間・得点入力に戻る」で第2段階入力画面に戻れる
10. 「登録」を押すまでDB登録されない
11. 「登録」を押すと createStats() が実行される


### 整合性チェック
#### 登録対象の整合性
1. 所属選手全員が登録対象になる
2. 出場選手として選択した選手は、入力したスタッツが登録対象になる
3. 出場選手として選択していない選手は、各スタッツが0として登録される
4. 出場選手として選択していない選手は、出場時間が0秒として登録される
5. 出場選手として選択していない選手は、画面上でDNPとして表示できる
6. 所属選手全員のスタッツがYup検証の対象になる
7. 選択していない選手の初期値（すべて0）もYup検証の対象になる
8. 所属選手全員のYup検証に成功した場合、全選手分のスタッツがcreateStats()に渡される
9. 1人でもYup検証に失敗した場合、DB登録されない

#### 出場時間の合計チェック
1. 所属選手全員の出場時間の合計が12,000秒の場合、登録できる
2. 所属選手全員の出場時間の合計が12,000秒未満の場合、エラーメッセージが表示されて登録できない
3. 所属選手全員の出場時間の合計が12,000秒を超える場合、エラーメッセージが表示されて登録できない
4. 出場時間の合計が12,000秒でない場合、DB登録されない
5. 出場時間の合計が12,000秒の場合、`createStats()`が実行される
6. Server Action側でも出場時間の合計が12,000秒でない場合、DB登録されない

#### 得点合計チェック
1. 所属選手全員の得点合計が試合の最終スコアと一致する場合、登録できる
2. 所属選手全員の得点合計が試合の最終スコアを下回る場合、エラーメッセージが表示されて登録できない
3. 所属選手全員の得点合計が試合の最終スコアを上回る場合、エラーメッセージが表示されて登録できない
4. 得点合計が試合の最終スコアと一致しない場合、DB登録されない
5. 得点合計が試合の最終スコアと一致する場合、createStats()が実行される
6. Server Action側でも得点合計が試合の最終スコアと一致しない場合、DB登録されない
