# 画面遷移チェックリスト

## 目的
アプリ内の主要な画面遷移が正しくつながっていることを確認する。<br>
細かな機能やバリデーションよりも、現時点では画面間の導線を優先して確認する。

## トップ
- (済) トップ → チーム一覧
- (済) トップ → 試合一覧

## チーム・選手
- (済) チーム一覧 → チーム登録
- (済) チーム一覧 → チーム詳細
- (済) チーム詳細 → チーム編集
- (済) チーム詳細 → 所属選手一覧
- (済) 所属選手一覧 → 選手登録
- (済) 所属選手一覧 → 選手詳細
- (済) 選手詳細 → 選手編集

## 試合
- (済) 試合一覧 → 試合登録
- (済) 試合一覧 → 試合詳細
- (済) 試合詳細 → 試合編集

## スタッツ
### ホームチーム
- (済) 試合詳細 → ホームスタッツ新規登録
- (済) 試合詳細 → ホームスタッツ編集

### アウェイチーム
- (済) 試合詳細 → アウェイスタッツ新規登録
- (済) 試合詳細 → アウェイスタッツ編集

### スタッツ登録後・編集後
- (済) スタッツ新規登録 → 試合詳細 + スタッツ一覧
- (済) スタッツ編集 → 試合詳細 + スタッツ一覧

## 各画面から戻る導線
- (済) 各画面 → トップ
- (済) 各画面 → 直前の一覧・詳細画面

## 登録データが0件の場合
各一覧画面で登録データが0件の場合、新規登録画面へ遷移するボタンを表示する。
- (済) チーム0件 → チーム新規登録
- (済) 選手0件 → 選手新規登録
- (済) 試合0件 → 試合新規登録
- (済) スタッツ0件 → スタッツ新規登録

## スタッツの登録状態による導線
試合詳細 + スタッツ一覧画面では、チームごとのスタッツ登録状態に応じてボタンを切り替える。

### スタッツ未登録
- (済) ホームチーム → ホームスタッツ新規登録
- (済) アウェイチーム → アウェイスタッツ新規登録

### スタッツ登録済み
- (済) ホームチーム → ホームスタッツ編集
- (済) アウェイチーム → アウェイスタッツ編集

## スタッツ新規登録のURL
- (済) ホームチーム<br>
  /games/[gameId]/stats/new?team=home
- (済) アウェイチーム<br>
  /games/[gameId]/stats/new?team=away


## スタッツ編集のURL
- (済) ホームチーム<br>
  /games/[gameId]/stats/edit?team=home
- (済) アウェイチーム<br>
  /games/[gameId]/stats/edit?team=away

## スタッツ新規登録・編集の設計
新規登録と編集の両方をチーム単位で操作する設計に統一した。

### 新規登録
1チームの出場選手を選択する。<br>
選択した選手のスタッツを1人ずつ入力する。<br>
登録完了後、試合詳細 + スタッツ一覧画面へ戻る。

### 編集
指定したチームの登録済みスタッツを一覧表示する。<br>
複数選手のスタッツをまとめて編集する。<br>
保存完了後、試合詳細 + スタッツ一覧画面へ戻る。
