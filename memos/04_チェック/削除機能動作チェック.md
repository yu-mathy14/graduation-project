# 削除機能動作チェック

## 選手削除

### 削除可能な選手
- スタッツがない選手は、選手詳細画面に[削除]リンクが表示される
- [削除]リンクから削除確認画面へ遷移できる
- 選手名が削除確認画面に表示される
- [キャンセル]を押すと選手詳細画面へ戻る
- [削除]を押すと選手が削除される
- 選手削除後、所属選手一覧画面へ遷移する
- 削除した選手が所属選手一覧から表示されなくなる

### 削除不可の選手
- スタッツがある選手は、選手詳細画面に[削除]リンクが表示されない
- 削除できない理由が表示される
- `/delete`へ直接アクセスした場合、削除不可画面が表示される
- 削除不可画面の[了解]を押すと選手詳細画面へ戻る
- Server Action実行時に削除不可の場合、削除処理が実行されない
- Server Action実行時に削除不可の場合、削除確認画面の削除不可表示へ戻る

## 試合削除

### 削除可能な試合

- 試合スタッツがない試合は、試合詳細画面に[削除]リンクが表示される
- [削除]リンクから削除確認画面へ遷移できる
- ホームチーム名・アウェイチーム名が削除確認画面に表示される
- [キャンセル]を押すと試合詳細画面へ戻る
- [削除]を押すと試合が削除される
- 試合削除後、試合一覧画面へ遷移する
- 削除した試合が試合一覧から表示されなくなる

### 削除不可の試合

- 試合スタッツがある試合は、試合詳細画面に[削除]リンクが表示されない
- 削除できない理由が表示される
- `/delete`へ直接アクセスした場合、削除不可画面が表示される
- 削除不可画面の[了解]を押すと試合詳細画面へ戻る
- Server Action実行時に削除不可の場合、削除処理が実行されない
- Server Action実行時に削除不可の場合、削除確認画面の削除不可表示へ戻る
