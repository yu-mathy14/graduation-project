# 詳細画面
## 詳細画面作成手順
チーム一覧画面から遷移するチーム詳細画面を作る時の場合
### 0. 必要なフォルダ・ファイルの作成
```
app/teams
     │
     ├── [teamId]
     │    └── page.tsx // 詳細画面⭐︎
     └── page.tsx // 一覧画面
```

### 1. [teamId]でURLの値を受け取る
詳細ページが表示できるかを確認する。
``` tsx
type Props = { 
  params: Promise<{teamId: string}>;
};

export default async function TeamDetailPage({ params }: Props) {
  const { teamId } = await params;
  
  return (
    <div>
      <p>チームID：{teamId}</p>
    </div>
  )
}
```

```
URL -> teamId取得 -> Prisma検索 -> チーム表示 -> 選手検索
```
上記の流れを一気にやると、どこで問題が起きたかがわかりにくくなるため、<br>
最初にURLの値の受け渡しが上手くできているかを確認した方がいい。

### 2. PrismaでID取得->情報表示を作る
手順1が問題なければ、Prismaを使った詳細画面を作り始める。


## 選手詳細画面
### 1. Propsで渡すもの
SOSO：playerIdのみ
``` tsx
type Props = {
  params: Promise<{playerId: string}>;
};

export default async function PlayerDetailPage({ params }: Props) {
  const { playerId } = await params;
  const id = Number( playerId ); // playerId(文字列)を数値に変換し、idに格納
/* 以下略 */
}
```
---
BETTER：playerIdとteamIdの両方
``` tsx
type Props = {
  params: Promise<{
    teamId: string;
    playerId: string;
  }>;
};

export default async function PlayerDetailPage({ params }: Props) {
  const { playerId, teamId } = await params;
  const pId = Number( playerId ); // playerId(文字列)を数値に変換し、pIdに格納
  const tId = Number( teamId ); // teamId(文字列)を数値に変換し、tIdに格納
/* 以下略 */
}
```

### 2. 該当データの取得と確認
SOSO：取得したplayerの存在のみを確認
``` tsx
export default async function PlayerDetailPage({ params }: Props) {
/* ------省略------ */
  // Prismaを使ってPlayersテーブルから該当の選手情報(1件)を取得
  const player = await prisma.players.findUnique({
    where: { playerId: pId },
  });

// ⚠️ここ========================================
  /* 選手が見つからなかった場合、404ページを表示する */
  if (!player) notFound();
// ⚠️===========================================

  // Prismaを使ってTeamsテーブルから該当のチーム情報(1件)を取得
  const team = await prisma.teams.findUnique({
    where: { teamId: tId },
  });

  /* チームが見つからなかった場合、404ページを表示する */
  if (!team) notFound();
/* ------省略------ */
}
```

URLのteamIdと選手の所属チームが一致しているか確認していなかった状態<br>
例
```
/teams/1/players/20
```
というURLで、選手20が本当はチーム2所属だったとしても<br>
選手20とチーム1を別々に取得して表示してしまう。
---
BETTER：playerの存在確認をしたら、<br>
URLのteamIdと、選手の実際の所属チームが一致するか確認
``` tsx
export default async function PlayerDetailPage({ params }: Props) {
/* ------省略------ */
  // Prismaを使ってPlayersテーブルから該当の選手情報(1件)を取得
  const player = await prisma.players.findUnique({
    where: { playerId: pId },
  });

  /* 選手が見つからなかった場合、404ページを表示する */
  if (!player) notFound();

// ⭐️これを追加======================================
  // URLのteamIdと、選手の実際の所属チームが一致するか確認
  if (player.teamId !== tId) {
    notFound();
  }
// ⭐️===============================================

  // Prismaを使ってTeamsテーブルから該当のチーム情報(1件)を取得
  const team = await prisma.teams.findUnique({
    where: { teamId: tId },
  });

  /* チームが見つからなかった場合、404ページを表示する */
  if (!team) notFound();
/* ------省略------ */
}
```
