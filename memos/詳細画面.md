# 詳細画面
## 詳細画面作成手順
チーム一覧画面から遷移するチーム詳細画面を作る時の場合
### 0. 必要なフォルダ・ファイルの作成
```
app/teams
     │
     ├── [teamId]
     │    └── page.tsx // 詳細画面⭐︎
     └── page.tsx // 一覧画面
```

### 1. [teamId]でURLの値を受け取る
詳細ページが表示できるかを確認する。
``` tsx
type Props = { 
  params: Promise<{teamId: string}>;
};

export default async function TeamDetailPage({ params }: Props) {
  const { teamId } = await params;
  
  return (
    <div>
      <p>チームID：{teamId}</p>
    </div>
  )
}
```

```
URL -> teamId取得 -> Prisma検索 -> チーム表示 -> 選手検索
```
上記の流れを一気にやると、どこで問題が起きたかがわかりにくくなるため、<br>
最初にURLの値の受け渡しが上手くできているかを確認した方がいい。
